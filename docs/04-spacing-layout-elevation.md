# 04 · 间距 · 布局 · 层级

> 空间系统回答三个问题：**放多大**（间距）、**排哪里**（网格/断点）、**谁在上面**（elevation/z-index）。答案必须唯一且可被 AI 确定性执行。

---

## 一、间距刻度（4px 基数）

| Token | px | 用途 |
|---|---|---|
| `--m-space-05` | 2 | 控件内部细节（徽章 py、焦点微调） |
| `--m-space-1` | 4 | 图标与文字间距、紧凑内衬 |
| `--m-space-2` | 8 | 相关元素间 gap（icon+label）、卡片内行距 |
| `--m-space-3` | 12 | 控件内边距（sm 按钮）、列表项 gap |
| `--m-space-4` | 16 | **默认节奏**：卡片内边距、表单字段间、网格 gutter(移动) |
| `--m-space-5` | 20 | lg 按钮内边距 |
| `--m-space-6` | 24 | 卡片分组间、后台 section 间 |
| `--m-space-8` | 32 | 前台卡片组间、后台页面级间距 |
| `--m-space-10/12` | 40/48 | 前台小区块间 |
| `--m-space-16/20/24` | 64/80/96 | 前台大区块间 |
| `--m-space-section` | clamp(48→96) | 前台区块统一节奏（响应式自动） |

**规则**：gap/padding 只出现在这张表里（+组件 token）。8 的倍数优先；4 的倍数兜底；2px 仅控件内部。后台密度更紧：卡片 16px、表格单元格 12px、字段间 16px。

## 二、网格与容器

### 前台

| 项 | 规格 |
|---|---|
| 内容容器 | `max-w: 1280px`（`--m-container-storefront`），gutter 移动 16 / 桌面 24 |
| 窄栏（政策/博客） | `--m-container-narrow` 640px |
| 商品网格（PLP） | 移动 2 列（gutter 8-12）/ 平板 3 列 / 桌面 4 列（服饰类 3 列大图可选） |
| 区块 rhythm | 上下 `--m-space-section`；交替底色用 `bg-band`，同一页面 banding ≤3 次 |
| Hero | 高度自适应内容，禁止 100vh 锁定（移动地址栏跳动） |

### 后台

| 项 | 规格 |
|---|---|
| 应用框架 | 左侧导航 240px（≤1024px 折叠为 56px 图标栏）+ 顶栏 56px + 内容区 |
| 内容宽度 | 标准 `--m-container-admin` 1000px；窄（表单）640px；宽（数据表）自适应 + 24px 边距 |
| 页面内边距 | 16px（≤768px）/ 20px（默认）/ 32px（>1280px） |
| 卡片栅格 | 仪表盘 KPI：4 列（>1280）/ 2 列（≥768）/ 1 列；卡片间 16px |

### 断点（全系统唯一）

`xs 480 / sm 768 / md 1024 / lg 1280 / xl 1440`。JS 与 CSS 同值。**320px 可用性是底线**（最小测试视口，无横向滚动）。

## 三、Elevation（海拔）

四个阴影层级 + 一条"边框优先"总规则：

| 层 | Token | 用途 | 前台 | 后台 |
|---|---|---|---|---|
| 0 | 无 | 静态卡片 | 边框 e0 + 可选 e1 | **只用边框** |
| e1 | `--m-shadow-e1` | 商品卡、悬浮卡 | ✅ 常规 | hover 提示时才用 |
| e2 | `--m-shadow-e2` | Dropdown / Popover / Combobox 面板 | ✅ | ✅ |
| e3 | `--m-shadow-e3` | 抽屉、模态、命令面板 | ✅ | ✅ |
| e4 | `--m-shadow-e4` | Toast（最高层） | ✅ | ✅ |

深色模式阴影加深（tokens.css 已配对）。**禁止**用阴影表达"品牌感"——前台卡片的浮起感 = 细边框 + e1，不多不少。

## 四、Z-index 阶梯（封闭枚举）

```
raised  10   局部悬浮（sticky 表头、卡片内浮层）
nav     100  顶栏/侧栏
drawer  300  购物车抽屉、筛选抽屉
modal   400  模态、命令面板（⌘K）
toast   500  通知
tooltip 600  气泡（永远最上）
```

嵌套规则：模态内只允许 tooltip（600）与自身的 toast。抽屉上开模态 = modal(400) > drawer(300) 自动成立。**自造数值 = 校验失败。**

## 五、圆角

主旋钮 `--m-radius: 8px`，派生：xs 2 / sm 4 / **md 8（控件、输入框、按钮）** / **lg 12（后台卡片）** / **xl 16（前台卡片、媒体、抽屉）** / 2xl 24（前台大模态）/ pill（徽章、swatch）。

组合规则：嵌套时内层 ≤ 外层（卡片 16 内的按钮 8 ✓）；媒体图与所在容器同角或内缩（图片 12 在卡片 16 内 ✓）。品牌可在 Brand Kit 改 `--m-radius`（6→12 整套缩放，shadcn 旋钮法）。

## 六、焦点环（双规格）

| 舞台 | 规格 |
|---|---|
| 前台 | 外环：`box-shadow: 0 0 0 2px bg-page, 0 0 0 4px border-focus`（offset 2px 外扩） |
| 后台 | 内嵌环（Polaris 式）：紧贴控件边框内侧 2px `border-focus`，不挤占布局 |

颜色永远 `--m-border-focus`（对任意 surface ≥3:1，WCAG 2.4.11）。**永远 `:focus-visible`**，鼠标点击不出现环。已在 tailwind-theme.css base 层全局实现，组件层禁止重写。

## 七、触达尺寸

| 场景 | 最小 |
|---|---|
| 任何可点元素（WCAG 2.5.8） | 24×24px |
| 移动端主 CTA / 行内可点项 | 44×44px |
| 相邻触达目标间距 | ≥8px |
| Swatch / 数量步进器 | 视觉 24px + 热区扩展至 44px |
