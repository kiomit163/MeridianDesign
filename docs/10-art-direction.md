# 10 · 美术指导（Art Direction）

> 第九章之前，这份规范管住了"不出错"。这一章管"有品格"。
>
> **为什么需要单列一章**：v1.5 及其之前，六个表达槽位全部空着——衬线 display 从未被引用、插画被写成 24px 的图标槽、影像只有三行比例规则、表达性动效预算留给了不存在的素材、品牌渐变只用在文档站自己的 logo 上。结果是：每一项都合规，每一页都记不住。约束不产生风格，**决策才产生风格**。

---

## 一、三条立场（先于任何具体规则）

1. **美术指导是决策的前置，不是事后的修饰。** 在画第一版布局之前就必须回答："这一页希望被记住的是哪一件事？"答不出来，就不要开始画。允许的答案是"记不住"（例如设置页），但必须是被选中的，而不是默认结果。
2. **每页只允许一个视觉主张。** 一个页面里同时出现 hero 巨字、渐变卡、动效、插画，等于没有主张。主张之外的一切保持安静——这是"克制"的真实含义，不是"少用颜色"。
3. **风格可以被继承，但必须被声明。** 明示"对标 Shopify Dawn"是合法策略（Dawn 转化率经过验证），但它是一个**选择**，需要写进项目决策记录并承担"不可辨识"的后果。不得在未声明的情况下滑入某个默认外观。

## 二、影像指导（Photography）

商品是主角，但"让版面为图让路"不是一条可执行的规则。以下可执行。

### 2.1 主图规格

| 项 | 规则 | 判据 |
|---|---|---|
| 主体占比 | 主体占画面 **55%–75%** | 小于 55% 商品在缩略图里消失；大于 75% 失去呼吸 |
| 背景 | 单一色，明度与 `--m-bg-inset` 差值 ≤ 8 L* | 否则卡片边缘与图分离，网格碎裂 |
| 用光 | 主光与辅光比 **≤ 1:3**；允许一条硬阴影，禁止多向硬影 | 多向硬影是"棚拍廉价感"的主因 |
| 裁切安全区 | 外扩 8% 后仍完整包含主体 | 网格与 4:5/1:1 切换时不切到主体 |
| 序列 | **必守**：图 1 全貌 → 图 2 材质微距 → 图 3 上身/使用 → 图 4 细节（拉链/走线/接口） | 这是"能买"与"不敢买"的分界，不是审美偏好 |
| 视频 | ≥1 条，静音可循环，首帧必须是图 1 的同构图 | 换构图会造成点击后的认知断裂 |

### 2.2 序列为什么是硬规则

PDP 画廊只规定"4–8 张 + ≥1 视频"是不够的：8 张随便拍的全貌图，信息量低于 4 张有序列的图。**序列是被验证过的转化结构**，因此它属于规范，不属于摄影师的自由。

### 2.3 禁止

- 抠图白底 + 投影贴纸式组合（读起来是 marketplace，不是品牌）
- 同一页混用两种背景处理（一半灰底一半实景）
- 用 `opacity` 变暗图片来表达"缺货"以外的任何状态

### 2.4 影像来源与披露（v1.7 · 结构层）

> 本节登记**必填字段与可见物**，不判定法律义务的范围——哪些市场、哪些类目强制披露由法务复核（`docs/06 §7.1`）。复核结论落地前，结构能力必须存在且不可关闭。

| 项 | 规则 |
|---|---|
| 来源枚举 | `provenance` 四值封闭：`photograph` / `ai-generated` / `ai-retouched` / `illustration`。每份商品影像（含视频 poster）必须登记，不得留空 |
| 机器可读元数据 | 至少一种：C2PA manifest，或 IPTC `DigitalSourceType`（`trainedAlgorithmicMedia` / `compositeWithTrainedAlgorithmicMedia`）；上传链路不得剥离来源元数据 |
| 登记字段 | 工具/模型、生成或拍摄日期、授权/版权来源；与素材同生命周期保存，供审计与撤回 |
| 可见披露 | `ai-generated` / `ai-retouched` 必须带可见披露（badge 或 caption），**不得只写在 EXIF/元数据里**；`photograph` / `illustration` 不强制 |
| badge 规格 | 最小高度 `--m-badge-h`（20px）、文字 `--m-text-xs`（12px）、不透明 `m-badge--neutral`（禁止半透明叠图）；距图片底边 8px，置于阅读起点侧（LTR 左下 / RTL 右下）；文字对比度 ≥4.5:1 |
| 小图退化 | 图片渲染高度 <240px 时，badge 退化为相邻 `<figcaption>`，不得覆盖主体或缩略图 |
| 视频 | 披露固定在 poster 与播放首 2s 内可见；播放器控件旁保留持久文本入口 |
| 真实摄影底线 | PDP 图组至少 1 张 `photograph`；`ai-generated` 不得作为唯一主图；`ai-retouched` 必须与真实摄影同组并披露 |
| 文案封闭集 | 只允许 `docs/08 §五` 的三个 key；禁止自由文本只写 "AI"（无法区分生成与修饰） |

> 原型现状：`prototypes/08–11` 的商品图均为本地 SVG 插画，登记为 `illustration`。"至少 1 张真实摄影"是**生产契约**，不是当前样张已满足的事实。

## 三、插画系统（Illustration）

### 3.1 先修一个误导性名词

此前三处文档写 "illustration"，而括号里给的是 **24px 区域**——那是图标尺寸档位的端点。按字面实现的人只有两个选择：塞一个图标（得到一个"看起来缺图"的空态），或者临时约一张插画（破坏一致性）。**这是规范自身的缺陷，不是实现者的失误。**

### 3.2 插画契约

| 项 | 规则 |
|---|---|
| 画布 | 240×160（空态）、480×320（引导态）；4:3 与 3:2 两档，不得自造 |
| 笔触 | 与图标同源：**1.5px 主线**，圆角端点，与 `.m-i` 一致 |
| 配色 | 仅 `ink` 中性阶 + **一个**强调色（`--m-primary` 或语义状态色之一），禁止全彩 |
| 隐喻 | 必须表达"下一步做什么"（空盒子 → 去创建；空文件夹 → 去上传），禁止纯装饰 |
| 无障碍 | 装饰性 → `aria-hidden="true"`；承载信息 → `role="img"` + `<title>` |

### 3.3 空态的完整配方（替代"三件套"的含糊表述）

```
插图 240×160（aria-hidden）
+ H4 标题（≤ 12 字，名词短语）
+ 一句解释（≤ 40 字，说明"为什么是空的"）
+ 一个主 CTA（动词+名词）
+ 可选一个次级中性动作（如"获取灵感"）
```

> 次级动作是允许的：真实产品里"从零开始"与"从模板开始"同等重要。此前的单 CTA 规定过严。

## 四、版式原型（Page Archetypes）

拓扑 A/B 只回答了"背景怎么排"，没回答"内容怎么排"。以下四个原型可直接套用；不符合任一原型时，必须显式说明理由。

### A · 陈述型（Hero）

用于首页、活动页、品牌故事。

```
┌──────────────────────────────────────────┐
│ eyebrow（≤ 3 词，全大写字距 0.14em）      │
│ H1（display 字号，≤ 8 词，1.05 行高）     │
│ lead（≤ 2 行，--m-weight-regular）        │
│ [主 CTA] [次级 CTA]                       │
│ ───────────────────────────────────────── │
│ 视觉主体（3:2 / 16:9，占视口 45–65%）      │
└──────────────────────────────────────────┘
```
铁律：**H1 与视觉主体之间不得插入第三个信息块**。插入即降为 B。

### B · 索引型（Index）

用于集合页、搜索结果、任何"很多同类项"。

```
标题 + 计数 + 排序/筛选条（sticky）
网格：≥1280 → 4 列；768–1279 → 3；<768 → 2
每卡：图（4:5）→ 名称（≤2 行）→ 价格 → 一个次级信息
```
铁律：**卡片内的信息层级不得超过 4 级**。第 5 级说明这是详情页，不是索引页。

### C · 叙事型（Editorial）

用于内容页、品牌故事、长文。

```
栏宽 68ch；图可出血至容器边缘
每 2–3 段出现一次视觉停顿（图 / 引用 / 数据行）
引用块：2px 左侧条 + `--m-text-2xl` 字号 + `--m-weight-regular`（`.sf-prose blockquote` 未覆写权重，继承默认）
```
铁律：**连续纯文本不得超过 3 段**。第四章的 `.sf-prose` 已实现此结构，但从未被使用——原型必须至少有一页示范它。

### D · 工作台型（Workbench）

用于后台、编辑器、创作者工具。

```
[外壳] 侧栏 240（chrome 阶）│ 台面（surface 阶）
台面内：PageHeader（标题 + 主操作 + 次操作）
      → 工具条（筛选/视图/批量）
      → 内容（表格 / 卡片 / 画布）
```
铁律：**主操作永远在页头右端，不在表格里**。表格里只放行级动作。

## 五、字体作为身份

`--m-font-display` 目前是空槽。以下为填充规则。

| 舞台 | display 选择 | 理由 |
|---|---|---|
| 前台 · 服饰/家居/美妆 | 衬线（Source Serif / Fraunces / Playfair） | 与"慢"、"手工"、"材质"的语义同构 |
| 前台 · 科技/运动 | 窄体无衬线（Geist / Archivo Narrow） | 速度与精密 |
| 后台 / 工具 | **禁止使用 display**，一律 `--m-font-sans` | 工具不需要人格，需要可扫读 |

三条硬规则：

1. **display 只用于 H1 与品牌字标**，不得用于卡片标题、按钮、表头。
2. **中文与拉丁必须成对选择**：一旦选择衬线拉丁，中文必须配宋/明体系（思源宋体），不得用黑体硬配——这是"混排不成立"的最常见来源。
3. **字距按脚本分化**：拉丁标题可用 `-0.02em`，**汉字标题必须为 0**；`.sf-brand` 的 `0.14em` 只适用于拉丁全大写字标。

## 六、品牌时刻清单（Brand Moments）

品牌色只允许出现在下列七处。每处都必须**真的出现**，否则该页面视为"未完成"，而不是"合规"。

| # | 时刻 | 必须包含 |
|---|---|---|
| 1 | 字标 | 品牌字体 + 品牌色（不得用纯文本顶替） |
| 2 | 宣告条 | 品牌底 + 反白字（禁止用中性底） |
| 3 | 首屏 | 一个与商品无关但表达立场的句子 |
| 4 | 营销区块 | 品牌色块或品牌影像，二者其一 |
| 5 | 强调徽章 | 促销/新品，`accent` 实底 |
| 6 | 空态插画 | 见 §三 |
| 7 | 页脚 | 品牌语 + 注册信息（合规要求同处） |

> 现状核对：v1.5 的店面样张里，1–4 全部缺失或中性化，5 存在，6 被降级为图标，7 存在。**七个时刻里只兑现了两个。**

## 七、评审口径

一份页面"合规"与"有品格"是两道门，必须分别过。

### 7.1 合规门（机器可查）

对比度、焦点环、触达尺寸、token 使用、断行、动效降级——由 `validate.mjs` 与 selfcheck 断言。影像来源与披露（四值枚举、C2PA/IPTC、可见 badge/caption）由 R13 与 conformance 断言。

### 7.2 品格门（人工，必须留证）

回答三个问题，答案写入 PR 描述：

1. **这一页希望被记住的一件事是什么？** 答"无"是合法答案，但仅限工具页。
2. **它出现在哪三个同类产品里会显得不同？** 若答案是"不会不同"，则须显式声明"对标 X"，并接受不可辨识。
3. **七个品牌时刻里，这一页兑现了几个？** 前台页 < 3 个即为未完成。

### 7.3 反模式清单（出现即打回）

- 首屏是一张占位图或灰色矩形
- 页面上的唯一颜色是促销红/状态色
- 标题与正文只有字号差异，没有字体或字重差异
- 动效只出现在 hover 上，页面加载没有任何编排
- 八个卡片等宽等高的网格，且每张卡片信息量相同
